# Análisis y predicción de la rotación de empleados

Proyecto final DataXperience – Universidad EAN.

## Objetivo

Analizar las características relacionadas con la rotación de empleados y desarrollar modelos de clasificación para predecir si un empleado abandonará la empresa.

## Tecnologías

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Modelos utilizados

- Regresión Logística
- Random Forest

## Resultados principales

El modelo Random Forest presentó un Accuracy aproximado del 99% y un Recall del 92% para la clase de empleados que abandonaron la empresa.

## Dataset

El conjunto de datos contiene información relacionada con satisfacción, evaluación, proyectos, horas trabajadas, antigüedad, accidentes laborales, promociones, departamento y salario.
